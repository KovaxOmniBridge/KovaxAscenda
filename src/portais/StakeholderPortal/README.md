# Stakeholder Portal

Este portal foi desenvolvido para atender grupos estratégicos que não são funcionários nem clientes diretos da empresa, oferecendo uma solução centralizada, moderna e flexível.

**Público-alvo:**
- Grupos específicos externos à organização
- Parceiros de negócio
- Fornecedores
- Representantes
- Transportadoras
- Franqueados

## Exemplos de uso
- Fornecedores
- Parceiros
- Representantes
- Transportadoras
- Franqueados

## Sobre o template
Um portal único, totalmente configurável para múltiplos perfis de stakeholders. Permite personalização de fluxos, módulos, integrações e identidade visual, adaptando-se às necessidades de cada grupo estratégico.
