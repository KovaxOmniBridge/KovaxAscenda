# ⚡ Acesso Rápido - Explorador de Interfaces

## 🚀 3 Passos para Acessar Qualquer Interface

### 1️⃣ Abrir Painel Dev
```
Arquivo: desenvolvedor/dev-dashboard.html
Ou: http://localhost:3000/desenvolvedor/dev-dashboard.html
```

### 2️⃣ Ir para Aba "🎨 Explorar Interfaces"
```
Última aba do menu lateral
```

### 3️⃣ Selecionar Empresa + Clicar no Card
```
Dropdown → Escolher empresa
Grid → Clicar em qualquer interface
```
